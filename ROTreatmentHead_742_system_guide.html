02 · Display Icons

디스플레이 아이콘

디스플레이에 나타나는 표시의 의미입니다. 그림의 번호와 아래 표의 번호가 서로 대응합니다.

번호표시설명
5PM오후 12시 ~ 자정 12시 사이에 나타납니다. 시계 모드가 24시간으로 설정되면 나타나지 않습니다.
6MIN분 단위 입력 시 나타납니다.
7g/L소금량 표시로 gram/Liter 입니다.
8KG입력값이 kg(kilogram)임을 나타냅니다.
9네 자리 숫자시간 또는 프로그램 값을 표시하며, 오류 코드에도 사용됩니다.
11잠금/해제잠금 / 해제 상태 표시.
12X2재생을 2번 한다는 뜻입니다.
13재생 표시재생이 요청되면 깜빡이고, 재생 중에는 계속 켜져 있습니다.
14Salt Amount커서가 있을 때 소금량을 프로그래밍할 수 있습니다.
15Regeneration Time/Day커서가 있을 때 재생 날짜와 시간을 프로그래밍할 수 있습니다.
16Time/Day커서가 있을 때 현재 날짜와 시간을 설정할 수 있습니다.
17모래시계현재 모터가 동작하고 있음을 나타냅니다.
20Lbs / ft³재생제 양의 값을 표현하며 pound / cubic feet 입니다.
21수도꼭지현재 흐름 속도를 나타낼 때 표시되며 “0”으로도 표시될 수 있습니다.

25ParameterLevel 2 프로그램에 사용됩니다.

27Hardness762 컨트롤러와 함께 사용되는 표시입니다.
28Capacity시스템 용량을 예상하여 나타냅니다.
03 · Keypad

키패드 버튼

컨트롤러 전면의 4개 버튼입니다. 이후 설명에서는 아래 아이콘으로 표시합니다.

1아래쪽 화살표
2설정
3위쪽 화살표
4재생 버튼 컨트롤러에 명령하는 데 사용하며, 잠금 모드를 변경할 때 사용합니다.
Note버튼을 30초 동안 누르지 않으면 Normal operation mode로 돌아갑니다.
04 · Time / Day

시간 · 요일 설정

현재 시각과 요일을 맞추는 방법입니다.

01
Time / Day에 커서가 왔을 때 시간을 설정하려면 버튼을 누릅니다.
02
시간 표시가 깜빡이면 버튼으로 시간을 변경합니다. (분 단위 설정 가능)
03
시간 설정을 마치고 버튼을 누르면 DAY 설정 화면이 나타납니다.
04
버튼을 누르면 날짜 밑의 커서가 깜빡입니다.
05
버튼으로 오늘 날짜에 커서를 두고 버튼을 누르면 설정이 완료됩니다.
05 · Regeneration Time / Day

재생 시간 · 요일 설정

재생 사이클의 주기와 시작 시각을 설정합니다.

01
화면 오른쪽 상단 DAYS의 초기값 3을 0으로 바꿉니다.
02
Regeneration Time/Day에 커서가 옵니다.
03
버튼을 사용하여 재생 사이클 주기 및 시간을 설정합니다.
Note그림의 Cursor가 깜빡일 때 버튼을 눌러야 Flag가 표시됩니다. 이후 버튼을 눌러 다음 커서로 이동합니다.
06 · Cycle Time

사이클 타임 프로그래밍

각 재생 사이클(C#)의 시간을 개별로 설정합니다.

사이클단계
C1Backwash
C2Draw
C3Slow Rinse
C5Fast Rinse
C8Refill
01
버튼을 5초 동안 누르면 C# 설정 화면이 나타납니다.
02
버튼으로 시간을 변경한 뒤 버튼을 눌러 설정을 확인합니다.
07 · Immediate Manual Regeneration

즉시 수동 재생

즉시 수동 재생이 필요할 때 사용합니다.

01
버튼을 3초 동안 누르고 있으면 수동 재생이 시작됩니다.
02
다음 Cycle로 변경하려면 버튼을 같이 누릅니다.
03
재생 중에 버튼을 3초 동안 누르고 있으면 X2가 표시되며 두 번 연속 재생이 가능합니다.
04
화면에 보이는 숫자는 총 재생 시간이며, 아무 버튼이나 누르면 현재 Cycle 시간을 볼 수 있습니다.
Note재생을 중지하려면 버튼을 5초 동안 누릅니다. service mode로 돌아갑니다.
08 · Program Reset

프로그램 리셋

History value(H) 화면에서 초기 설정으로 되돌리는 방법입니다.

01
버튼을 5초 동안 누릅니다.
02
화면에 H0가 표시됩니다.
03
H0 화면에서 버튼을 5초 동안 누르면 150이 깜빡이며 표시됩니다.
04
Valve type 설정을 다시 하고 Resin 양을 재설정하면 완료입니다.

History 항목

H0H0Initial setting value (초기 설정값)
H1H1Days since last regeneration (마지막 재생 날짜)
H17H17Months since service (서비스 개월)
742 system742 system에서는 H0, H2, H17만 표시되며 설정할 수 있습니다.
09 · Troubleshooting

문제 해결

화면에 에러가 표시될 때의 원인과 조치입니다.

ProblemPossible causeSolution
ERR 1컨트롤의 전원은 연결되어 있으나 제어 작업 상태를 확인할 수 없습니다. 버튼을 눌러 재설정합니다.
ERR 2컨트롤의 전원이 60Hz와 일치하지 않습니다.전원을 껐다가 켜 봅니다. 문제가 계속되면 60Hz에 해당하는 컨트롤러 또는 AC 어댑터로 교체합니다.
ERR 3컨트롤러가 CAM의 위치를 수신하지 못해 Home position을 찾기 위해 계속 회전합니다.컨트롤러를 Home position에 임의로 맞춰 놓고 2분간 대기합니다. 모래시계 표시가 켜지고 모터가 동작합니다.
모터 열보호에 의해 모터가 멈췄습니다.모터를 냉각시키고, 피스톤 운동을 방해하는 잔해물을 제거합니다.
캠이 동작하지 않고 ERR 3이 계속 표시됩니다.
  1. 모터 연결 확인
  2. 모터 와이어 벨트가 모터와 컨트롤러 모듈에 연결되어 있는지 확인
  3. 광센서 연결 및 위치 확인
  4. 모터 기어와 캠 기어가 맞물려 있는지 확인
위 항목에 모두 이상이 없으면 ① 광센서 → ② 컨트롤러 → ③ 모터 순서로 교체합니다.
트윈 프로그래밍이 되어 있으나 상호 연결 케이블이 연결되어 있지 않습니다.시스템 모델을 확인합니다.
