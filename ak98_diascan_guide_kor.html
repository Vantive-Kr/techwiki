Diascan™ 클리어런스 측정

투석 효율을 실시간으로 측정하고 처방된 투석 용량이 충족되고 있는지 확인하는
Diascan™ 클리어런스 측정 기능의 원리와 사용 방법을 쉽게 설명합니다.

HCEN12609 Rev.02.2015 소요 시간 약 10분 투석실 운영자 대상
Section 9.1 — Overview

Diascan™이란 무엇인가?

Diascan은 AK98 투석기에 내장된 클리어런스 측정 기능으로, 투석 치료 중 실시간으로 혈액 정화 효율을 계산합니다.

K
mL/min
클리어런스 (Clearance)
단위 시간당 혈액이 정화되는 양. 사용 중인 투석막과 혈류속도에 따라 달라집니다.
Kt
mL (혈액 정화 누적량)
클리어런스 × 치료 시간
현재 치료에서 지금까지 정화된 혈액의 총 누적량입니다.
Kt/V
무차원 (목표: ≥ 1.2)
투석 용량 (Dialysis Dose)
Kt/V = 1.0이면 환자의 수분 분포 용적 전체가 1회 정화된 것입니다. 처방 목표치 달성 여부를 나타냅니다.
측정 원리 — 어떻게 클리어런스를 계산하나요?
도전율(conductivity) 측정 기반의 Diascan 원리 설명

Diascan은 투석막 전·후에서 투석액의 도전율(conductivity)을 측정합니다. 이 도전율 차이를 분석하면 소듐(Na⁺) 클리어런스를 계산할 수 있으며, 이는 요소(urea)를 비롯한 소분자 노폐물 전반의 클리어런스를 대표합니다.

임상 연구에 의해 이온성 투석량(Effective Ionic Dialysance)과 생체 내 요소 클리어런스(In Vivo Urea Clearance) 사이의 상관관계가 검증되어 있습니다. (Lindsay et al., AJKD, 2001)

📌 참고

Diascan으로 얻은 클리어런스 데이터는 혈액 요소 데이터를 기반으로 수집된 클리어런스 데이터와 대조하여 검증되었습니다.

Section 9.2 — Parameters

Diascan이 확인하는 3가지 파라미터

치료 시작 후 투석기가 측정·계산할 수 있는 핵심 수치들입니다.

K — Clearance
K
단위: mL/min
단위 시간당 혈액 정화량. 투석막 종류와 혈류속도(Qb)에 따라 결정됩니다.
Kt — Cumulative
Kt
K × 치료 시간(t)
현재까지 정화된 혈액의 누적 부피. 치료 진행에 따라 지속 증가합니다.
Kt/V — Dose
Kt/V
Kt ÷ V (분포 용적)
환자 맞춤형 투석 용량. Kt/V ≥ 1.2가 일반적인 적정 목표치입니다.
V
V(분포 용적)란 무엇인가요?
Kt/V 계산에 필요한 환자 개별 수분 분포 용적

V(분포 용적)는 환자 체내 요소(urea)가 분포되는 수분의 양(리터)으로, 환자의 건체중(dry weight)을 기반으로 추정합니다.

V값은 처방 담당 의사가 지정한 공식(Watson 공식 등)을 사용하여 계산하거나, 운영자가 직접 입력합니다. 정확한 Kt/V를 얻으려면 V값을 정확히 입력하는 것이 매우 중요합니다.

⚠ 중요

신뢰할 수 있는 Kt/V 값을 얻으려면 환자의 V(분포 용적)를 정확하게 입력해야 합니다. 의사와 협력하여 환자별로 올바른 값을 확인하세요.

Section 9.4 — Check Kt/V

Kt/V 확인 방법

환자의 분포 용적(V)을 설정한 후 Kt/V를 측정합니다. Watson 공식으로 자동 계산하거나 수동 입력할 수 있습니다.

V 입력 방법 선택 Distribution Volume Setup
2 OPTIONS
A
옵션 A — 수동 입력 (분포 용적을 이미 알고 있는 경우)
Distribution volume (manual) → 직접 값 입력
  1. Diascan 버튼을 누릅니다.
  2. Setup 탭에서 Distribution volume (manual)을 누릅니다.
  3. 환자의 분포 용적 값을 입력합니다.
  4. Setup 탭에서 Interval을 눌러 측정 간격을 선택합니다.
  5. Confirm을 눌러 측정을 시작합니다.
B
옵션 B — Watson 공식으로 자동 계산
Watson 탭 → 환자 정보 입력 → 자동 계산
  1. Diascan 버튼을 누릅니다.
  2. Watson 탭을 선택합니다.
  3. Enter parameters를 누릅니다.
  4. 화면에 표시된 환자 정보 항목(성별, 나이, 키, 건체중 등)을 입력합니다.
  5. Setup 탭으로 돌아가 Interval을 선택합니다.
  6. Confirm을 눌러 측정을 시작합니다.
⚠ Watson 공식 사용 시

처방 담당 의사가 Watson 공식 사용을 지시한 경우에만 선택하세요. 환자 정보를 정확하게 입력해야 신뢰할 수 있는 Kt/V 값을 얻을 수 있습니다.

✅ 측정 결과 표시 측정 결과는 클리어런스 측정 결과 표시 필드에서 확인할 수 있으며, 최근 측정값, 측정 시각, Diascan 버튼이 표시됩니다.

Section 9.6 — Set Kt/V Target

Kt/V 목표치 설정

치료 종료 시점까지 환자가 달성해야 할 Kt/V 목표치를 설정하고, 투석기가 남은 치료 시간을 자동 추정합니다.

⚠ 사전 조건

Kt/V 목표치를 설정하기 전에 먼저 환자의 V(분포 용적)를 입력해야 합니다. (섹션 9.4 참조)

Kt/V 목표치 설정 절차
Diascan → Setup → Alarm settings → Kt/V target
  1. Diascan 버튼을 누릅니다.
  2. Setup 탭을 선택합니다.
  3. Alarm settings를 누릅니다.
  4. Kt/V target을 누릅니다.
  5. 목표 Kt/V 값을 입력합니다.
  6. OK를 누릅니다.
  7. Activate를 눌러 활성화하고 메뉴를 닫습니다.
✅ 목표치 활성화 결과 투석기가 목표 Kt/V에 도달하기까지 남은 치료 시간을 추정합니다. Diascan 메뉴의 Time to target 항목에서 이 값을 확인할 수 있습니다.
Section 9.7 — Set Alarms

K 또는 Kt/V 하한 알람 설정

K 또는 Kt/V 값이 설정한 하한치 아래로 떨어지면 투석기가 알람을 발생시키도록 설정합니다.

⚠ 사전 조건

Kt/V 알람을 설정하기 전에 환자의 V(분포 용적)가 먼저 입력되어 있어야 합니다.

!
K 또는 Kt/V 하한 알람 설정 절차
Diascan → Setup → Alarm settings → K limit / Kt/V limit
  1. Diascan 버튼을 누릅니다.
  2. Setup 탭을 선택합니다.
  3. Alarm settings를 누릅니다.
  4. 알람 종류를 선택합니다:
    K limit — 클리어런스(K) 하한치 알람
    Kt/V limit — 투석 용량(Kt/V) 하한치 알람
  5. 알람을 트리거할 하한치 값을 입력합니다.
  6. OK를 누릅니다.
  7. Activate를 눌러 활성화하고 메뉴를 닫습니다.
✅ 알람 활성화 결과 K 또는 Kt/V 값이 설정한 하한치 아래로 내려가면 투석기가 알람을 발생시킵니다. 즉각적인 상황 확인 후 조치를 취하세요.
Section 9.8 — Factors & Cautions

측정에 영향을 미치는 요소

다음 상황에서는 클리어런스 측정 결과의 신뢰도가 낮아지거나 측정이 불가능할 수 있습니다.

🚨 CAUTION — 임상적 주의

의료적 판단은 Diascan 기능의 정보에만 근거해서는 안 됩니다. 다른 많은 요소들을 종합적으로 고려해야 합니다.

신뢰도 저하 요소
측정 정확도에 영향을 주는 설정

이중 바늘 vs 단일 바늘: 이중 바늘(double needle) 치료에서 측정 결과가 더 신뢰할 수 있습니다.

프로파일링 활성: 소듐 또는 중탄산염 프로파일링이 활성화된 경우 측정이 영향을 받을 수 있습니다.
