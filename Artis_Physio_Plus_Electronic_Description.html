4.2 Control / Protective 이중화 구조
4개 슬레이브 보드 각각의 제어 시스템과 Protective 시스템이 동일 부품을 이중으로 감시합니다.
  • 슬레이브 제어 시스템: 모터·밸브 등 부품 구동 담당 (각 슬레이브 보드)
  • Protective 시스템: 동일 부품 감시 및 일부 제어 (이중화) + 환자 안전 직결 부품(24V 릴레이, 정맥 클램프, 알람) 직접 제어
  • T1 테스트: 기동 시마다 Protective 시스템이 개시·수행 — 보호 회로 정상 동작 여부 자가진단
  • SPI 버스 마스터: Main Board가 4개 슬레이브 보드 대상 SPI 통신 마스터 역할 (듀얼포트 RAM + 68HC11 통신 프로세서)
