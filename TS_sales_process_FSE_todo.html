DEADLINE

10/20수리 완료작성일자 · 귀속월 = 10월

가격 협의 · 오더 생성 · 병원 확인을 기다리지 않습니다. 기준은 언제나 완료일, 마감은 다음 달 10일.

TO-DO BY STAGE

단계별 할 일

유상수리 요청이 들어오면 위에서 아래로 진행하세요.

매월10일경 · 정기 확인
  1. 선입금 거래처 리스트(엑셀) 확인C2C가 매월 10일경 발송 — 내 담당 병원이 있는지 확인해 둡니다.
출동 전요청 접수 ~ 작업 시작
  1. “유상수리입니다” 명확히 안내요청한 병원 담당자에게 유상임을 먼저 알립니다.
  2. 선입금 거래처인지 확인리스트에 있으면 선입금 후 진행. 금액이 확정되지 않았으면 “7일 이내 입금” 확인을 받고 진행.
  3. ERP 오더 생성 (가능하면 작업 전)오더가 늦어져도 공급 시기는 바뀌지 않습니다.
  4. 유상수리 고객 요청서 — 서면 동의장비·부품 정보 · 작업 범위 · 유상 명시 · 예상 금액(표준 단가 근거) · 지급 기일 · 추가 작업/가격 변동 시 기준
  5. 요청자와 비용 담당자를 구분해 확보요청자(간호사·인공신장실)와 별도로 비용 승인자 · 세금계산서 수신자 · 지급 담당자(의공과·구매과 등)의 이름과 연락처.
작업 완료현장에서 떠나기 전
  1. 완료일 확정·기록테스트까지 마치고 장비를 정상 사용할 수 있게 된 날. 부품만 판매했다면 고객 수령일, 설치 포함이면 설치 완료일.
  2. 서비스 작업 확인서 받기장비명·부품명·S/N · 작업일자 · 수행 작업·사용 부품 · 작동·인계 확인 · 유상 처리 문구 · 최종 범위·금액 · 엔지니어+고객 서명
  3. 세금계산서 수신 정보 확인HD·Acute·PD 거래 병원은 CS가 보유. 일회성 거래 병원은 현장에서 받아야 합니다.
완료 당일바로 공유
  1. 완료일 + 증빙을 즉시 공유받는 사람: 오더 담당자 / 세금계산서 발행 담당자. 보낼 것: 완료일 · 작업 확인서(또는 납품확인서·고객 확인 메일) · 최종 금액 · 비용 담당자 정보.
  2. 표준 단가로 발행 요청 — 가격 협의를 기다리지 않음작성일자 = 완료일, 발급 마감 = 다음 달 10일 (예: 10/29 완료 → 11/10, 11/2 완료 → 12/10).
발행 후조정·수금까지
  1. 가격 조정 요청이 오면 → 예외 절차로사유를 서면으로 받기 → 사전 안내가·실제 작업 범위 대조 → TS 매니지먼트 승인 → 감액분 마이너스 세금계산서 → 원거래와 증빙 연결 보관.
  2. 역발행 병원이 늦어지면 → 빠른 발행 요청“유상수리가 완료되었으니 역발행을 빨리 부탁드립니다.” 필요하면 CS를 통해 병원 담당자에게 요청.
  3. 입금까지 확인대금이 들어와야 거래가 끝납니다. Finance 애플리케이션(권한 부여 예정) 또는 C2C 파이낸스에 문의.

DO & DON'T

이렇게 하세요 / 이건 안 됩니다

DO
  • 작업 전에 예상 금액·범위·지급 기일 안내
  • 완료 즉시 완료일·증빙 공유
  • 표준 단가로 먼저 발행, 조정은 나중에
  • 요청자와 비용 담당자 따로 확보
  • 긴급 수리·가격 조정은 사유·승인을 서면으로
DON'T
  • 가격 협의가 끝날 때까지 발행 보류
  • 내부 오더 생성일을 완료일로 사용
  • 다음 달 10일을 넘겨 발행
  • 선입금 거래처에 입금 확인 없이 출동
  • 구두 합의만으로 가격 조정
EMERGENCY

응급 수리 (중환자실 등)일 때

사전에 지불 부서와 견적을 협의할 시간이 없을 때의 진행 순서입니다.

01
표준 단가 근거로 예상 작업 범위·예상 가격을 안내합니다 (부품 가격표 전체를 공개할 필요는 없음).
02
요청한 의료진에게 “의공과·구매과에서 비용 집행이 되도록 협조 부탁드립니다”라고 말한 뒤 진행합니다.
03
완료 후 표준 단가로 발행, 병원이 이의를 제기하면 가격 조정 절차로 처리합니다.
04
긴급 수리였다는 예외 사유와 승인을 서면으로 남깁니다.
