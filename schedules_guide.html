Schedules 메뉴에는 무엇이 있나요

Techwiki 왼쪽 메뉴의 Schedules 를 열면 두 묶음, 총 8개 항목이 나옵니다. 왼쪽은 휴가, 오른쪽은 작업 일정입니다. 각 묶음의 첫 항목이 “등록”, 나머지 3개가 지역별 캘린더입니다.

Annual Leave · 휴가4개 항목
내가 자리를 비우는 동안 거래처가 대체 담당자에게 연결되도록 하고, 팀이 서로의 휴가를 볼 수 있게 합니다.
  • 휴가 등록 · 대체 담당자 QR등록휴가 정보를 넣으면 QR·링크가 만들어지는 별도 앱이 열립니다.
  • 서울 휴가 캘린더보기서울 지역의 휴가만 월간 캘린더로 표시합니다.
  • 대전·광주 휴가 캘린더보기대전·광주 지역 휴가만 표시합니다.
  • 부산·대구 휴가 캘린더보기부산·대구 지역 휴가만 표시합니다.
Work Schedules · 작업 일정4개 항목
누가 언제 어느 거래처에서 무슨 작업을 하는지 팀 전체가 한 화면에서 확인합니다.
  • 작업 일정 등록등록담당자·거래처·작업 내용·지역·기간을 입력하는 폼입니다.
  • 서울 작업 일정보기서울 지역 작업 일정을 월간 캘린더로 표시합니다.
  • 대전·광주 작업 일정보기대전·광주 지역 작업 일정을 표시합니다.
  • 부산·대구 작업 일정보기부산·대구 지역 작업 일정을 표시합니다.

지역은 세 가지입니다 — 서울 / 대전·광주 / 부산·대구. 등록할 때 고른 지역의 캘린더에만 표시됩니다. 서울로 등록하면 부산·대구 캘린더에는 나오지 않습니다.

4Work Schedules

작업 일정 등록과 수정

작업 일정은 훨씬 단순합니다. 등록 → 캘린더에 표시 → 필요하면 캘린더에서 바로 수정·삭제, 세 단계뿐입니다. 로그인도, 관리자 승인도 없습니다.

1

메뉴 > Work Schedules > 작업 일정 등록

담당자 · 거래처/병원명 · 작업 내용(예: 정기 점검, 소모품 교체) · 지역 · 시작일 ~ 종료일 을 입력하고 [작업 일정 등록] 을 누릅니다. 다섯 항목 모두 필수입니다.

하루짜리 작업이면 시작일과 종료일을 같게 두세요. 지역은 처음에 “서울”로 되어 있으니 확인하고 바꾸세요.
2

등록되면 캘린더 링크가 바로 뜹니다

“등록되었습니다” 화면에 방금 넣은 내용이 한 줄로 요약되고, 해당 지역 작업 일정 캘린더 보기 → 링크와 작업 일정 추가 등록 링크가 나옵니다. 여러 건을 연달아 등록할 때 유용합니다.

3

캘린더에서 바를 누르면 수정 창

작업 일정 캘린더에서 기간 바를 클릭하면 작업 일정 수정 창이 열립니다. 담당자·거래처·작업 내용·지역·기간을 모두 고칠 수 있고, 왼쪽 아래 삭제 버튼으로 지울 수도 있습니다. 삭제 전에는 한 번 더 확인 창이 뜹니다.

지역을 바꿔 저장하면 그 일정은 원래 지역 캘린더에서 사라지고 새 지역 캘린더로 옮겨집니다.
4

캘린더 화면에서 바로 등록도 가능

작업 일정 캘린더 오른쪽 위의 ＋ 작업 일정 등록 버튼을 누르면 등록 화면으로 바로 넘어갑니다. 달 이동은 ‹ / 오늘 / › 버튼을 쓰세요.

작업 일정은 누구나 수정하고 삭제할 수 있습니다. 본인 확인 절차가 없으므로, 남의 일정을 고치기 전에는 담당자에게 먼저 확인해 주세요.

캘린더에서는 이렇게 보입니다

등록한 기간이 가로 막대로 표시됩니다. 여러 건이 겹치면 위아래로 층이 쌓이고, 막대가 주를 넘어가면 다음 줄로 이어집니다. 오늘 날짜는 동그라미로 표시됩니다.

휴가 캘린더

막대에 휴가자 → 대체 담당자 가 적힙니다. 막대 위에 마우스를 올리면 지역과 정확한 기간이 뜹니다. 클릭해도 아무 일도 일어나지 않습니다.

작업 일정 캘린더

막대에 담당자 · 거래처 · 작업 내용 이 적힙니다. 막대를 클릭하면 수정 창이 열립니다.

7FAQ

자주 묻는 질문

Q제 전화번호가 캘린더에 남거나 아무나 볼 수 있나요?
휴가 캘린더와 작업 일정 캘린더에는 전화번호가 아예 저장되지 않습니다. 캘린더에는 이름·기간(그리고 작업 일정의 경우 거래처·작업 내용)만 들어갑니다. 전화번호는 QR 코드나 링크를 연 사람에게만 보이며, 거기서는 이름과 함께 번호가 표시되고 눌러서 바로 전화를 걸 수 있습니다. 즉 QR을 준 거래처만 번호를 보게 되므로, QR·링크를 누구에게 보낼지는 신중히 정하세요.
Q휴가를 잘못 등록했어요. 제가 지울 수 있나요?
본인은 지울 수 없습니다. 휴가 기록의 수정·삭제는 관리자만 할 수 있습니다. 관리자는 앱의 관리 화면(구글 로그인)에서 휴가 캘린더 탭을 열어 해당 건을 삭제하면 되고, 삭제하는 즉시 Techwiki 캘린더에서도 사라집니다. 관리자가 연락처 자체를 삭제하면 그 연락처에 연결된 휴가도 함께 지워지고, 배포한 QR도 더 이상 동작하지 않습니다. 따라서 잘못 등록했다면 관리자에게 삭제를 요청한 뒤 다시 등록하세요.
Q등록했는데 캘린더에 안 보여요.
순서대로 확인해 보세요. ① 지역이 맞는지 — 대전·광주로 등록했다면 서울 캘린더에는 나오지 않습니다. ② 달이 맞는지 — 다음 달 휴가라면 › 버튼으로 달을 넘겨야 보입니다. ③ 새로고침 — 캘린더는 한 번 불러온 자료를 잠시 기억해 두므로, 방금 등록한 건은 페이지를 새로고침하면 나타납니다. ④ 그래도 안 보이고 화면 위에 “불러오지 못했습니다” 같은 안내가 떠 있다면 네트워크 문제이니 잠시 후 다시 열어 보세요.
Q지역을 잘못 골랐습니다.
작업 일정은 간단합니다. 원래 지역 캘린더에서 그 막대를 눌러 수정 창을 열고 지역만 바꿔 저장하면 새 지역 캘린더로 옮겨집니다.
휴가는 본인이 고칠 수 없습니다. 관리자에게 삭제를 요청한 뒤 올바른 지역으로 다시 등록해 주세요.
Q문자 앱 열기를 눌렀는데 자동으로 발송되나요?
아니요. 휴대폰의 기본 문자 앱이 수신자 번호와 안내 문구, 링크까지 채워진 상태로 열리기만 합니다. 내용을 확인하고 직접 발송 버튼을 눌러야 실제로 나갑니다. 보내기 전에 문구를 고쳐도 됩니다. 수신자가 여러 명이면 번호를 쉼표(,)나 줄바꿈으로 구분해 넣으세요.
Q대체 담당자를 매번 손으로 입력해야 하나요?
자주 쓰는 대체자는 관리자가 대체자 리스트에 이름·전화번호·지역과 함께 미리 등록해 둘 수 있습니다. 그러면 휴가 등록 화면에서 리스트에서 선택 탭으로 바꿔 이름만 고르면 번호가 자동으로 채워집니다. 지역을 먼저 고르면 그 지역 대체자만 보여 찾기 쉽습니다. 명단이 비어 있으면 안내 문구가 뜨니, 그때는 직접 입력을 쓰세요.
8Privacy & Care

개인정보와 주의할 점

두 기능 모두 사내에서 열리는 화면이지만, 휴가 QR만은 거래처가 보는 정보라는 점을 기억해 주세요.

캘린더에는 번호가 없습니다

휴가 캘린더·작업 일정 캘린더에 저장되는 항목에는 전화번호가 포함되지 않습니다. 캘린더만 봐서는 누구의 번호도 알 수 없습니다.

QR·링크는 번호를 보여 줍니다

QR을 스캔하거나 링크를 연 사람에게는 담당자(또는 대체자)의 이름과 전화번호가 표시됩니다. 필요한 거래처에만 배포하세요.

작업 일정은 누구나 고칩니다

로그인이 없어 남의 일정도 수정·삭제할 수 있습니다. 실수로 지우면 되돌릴 수 없으니, 남의 일정은 확인 후에 손대 주세요.

대체자에게 미리 알리기

대체 담당자로 지정하면 그 사람의 번호가 거래처에 노출됩니다. 등록 전에 본인에게 먼저 양해를 구해 주세요.

휴가 등록은 취소가 어렵습니다. 등록 버튼을 누르기 전에 이름·지역·기간·대체자를 한 번 더 확인해 주세요. 등록 후 수정·삭제는 관리자만 할 수 있습니다.

정리하면 — 휴가는 “거래처까지 이어지는” 정보, 작업 일정은 “우리끼리 보는” 정보입니다. 이 차이만 기억하면 두 메뉴를 헷갈릴 일이 없습니다.
