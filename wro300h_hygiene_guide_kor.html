경고 사항

소독제 및 세척제는 독성이 있을 수 있습니다. 안전 안경과 장갑을 착용하세요. 화학 소독 시 투석기를 WRO 300 H에서 분리하세요 (중앙 화학 소독 제외).

소독 3단계 구성

화학 소독 및 세척은 흡입(Intake) → 드웰(Dwell) → 헹굼(Rinse) 3단계로 구성됩니다. DIS 버튼의 점등 상태로 소독 진행 여부를 확인할 수 있습니다.

프로토콜 구성

10개 프로토콜, 각 11개 변수 설정 가능. 기본 선택 가능: 화학 소독-DIALOX(1번), 산성 세척(2번), 보존 처리(7번). GXP 또는 내부 서비스 모드에서 변경 가능합니다.

소독제 농도 계산Disinfectant Concentration Formula
흡입량 및 농도를 정확히 계산하는 공식
공식 계산 Vm = 3600 ml
변수 정의
Vm — WRO 300 H 내부 수량 (탱크 3500 ml + 제품수 루프 2×1 m = 100 ml) = 3600 ml
Km — WRO 300 H 내 목표 농도 (%)
Kc — 소독제 원액 농도 (%)
Vc — 소독제 흡입량 (ml)
계산 공식
Km = Kc × (Vc / Vm)  → WRO 내 용액 농도
Vc = Km × (Vm / Kc)  → 소독제 흡입량
계산 예시
Dialox® (원액 100%):
Vm=3600 ml, Km=3%, Kc=100% → Vc = 108 ml

희석 소독제 (75%):
Vm=3600 ml, Km=3%, Kc=75% → Vc = 144 ml

드웰 & 헹굼 단계Dwell & Rinse Phase · 2.5.3
흡입 완료 후 자동 진행되는 접촉 유지 및 세척 단계
단계 2·3 자동 진행 전도율 모니터링
드웰 단계 (Dwell)
소독액 접촉 유지 단계. 간헐 운전(Intermittent Run) 활성화 시 RO 펌프가 순환시간·정지시간 설정에 따라 동작합니다.
DIS 버튼으로 드웰을 언제든 중단하고 헹굼으로 전환 가능합니다.

간헐 운전은 프로토콜 2, 9, 10번 (ACIDCLEAN, WARM ACID CLEAN, MINNCLEAN®, ALKALINE CLEAN)에서 기본 활성화됩니다.

헹굼 단계 (Rinse) — 3단계 반복
1BYVA·REVA 열림 → RO 펌프 저속 시작 → 탱크 레벨 LL 이하 시 정지 → INVA 열어 LH까지 채움 (7회 반복)
2RO 펌프 2분 순환 (OFVA 열림, REVA 5초 열림)
3WRO 300 H 1분 정지

헹굼 마지막 5분간 전도율(C2) 확인. 통지 한계 미만이면 헹굼 완료. 초과 시 최대 30분 연장. 30분 후에도 초과 시 403 HIGH CONDUCTIVITY RINSE 알람.

동작 원리

참고

95°C 순환 투석기 제어
기능 설명
저유량 열처리 모드는 제품수 라인의 물을 가열하여 투석기의 inlet 부품에 열처리된 물을 공급합니다.

저유량 열처리 중에도 최대 95°C의 물이 분배 루프에 순환합니다.

제어 방식

저유량 열처리 모드의 지속 시간은 투석기가 제어합니다.

전원 장애 발생 시 전원 복구 후 절차가 재시작됩니다.

열 소독과의 차이
열 소독과 달리 투석기가 물을 소비하지 않을 때만 저유량 열처리가 진행됩니다 (투석기 미소비 시에만 WRO 루프에 열수 순환).
추가 기능Extra Functions · 2.6 3개 항목
절수 기능Water Save Function · 2.6.1
REVA 재순환으로 급수 절약 — RO 모듈 수명과 트레이드오프
S29 설정 20초 주기 RO 수명 단축
기능 원리
절수 기능은 거부수(reject water)를 폐기하는 대신 REVA(순환 밸브)를 통해 WRO 급수 입구로 재순환시켜 급수 소비를 줄입니다.
절수 계수 S29로 REVA가 열리는 횟수를 제어하며, 20초 주기로 동작합니다.
동작 조건
RUN 모드 시작 후 처음 2분 동안은 비활성화됩니다 (시스템 안정화 대기). 이후 S29 설정값에 따라 자동 작동합니다.

절수 기능은 RUN 모드에서만 작동하며, 소독 모드 중에는 동작하지 않습니다.

회수율 (Recovery Ratio)
S29 = 0 → 절수 비활성 (표준 동작)
S29 = 1~9 → 낮을수록 절수 효과↑, RO 수명↓
높은 S29 값 → 더 많은 거부수 배출, RO 수명 보호
주의

절수 기능을 사용하면 거부수 미네랄 농도가 증가하여 RO 모듈 수명이 단축될 수 있습니다. 병원 수질 조건에 따라 적절한 S29 값을 설정하세요.

리마인더Reminders · 2.6.2
STANDBY 시 트리거되는 최대 5개 정기 알림 기능
최대 5개 STANDBY 트리거 28자 메시지
리마인더 개요
WRO 300 H는 정기 유지보수, 소독 일정 등을 상기시키는 최대 5개의 리마인더를 동시에 설정할 수 있습니다.
리마인더는 STANDBY 모드 진입 시 트리거됩니다.
시간 주기 설정
리마인더 반복 주기(일 단위)는 내부 서비스 모드(Internal Service Mode)의 S-번호를 통해 설정합니다.

시간 주기 설정은 GXP 모드가 아닌 내부 서비스 모드에서만 변경 가능합니다.

메시지 텍스트 설정
리마인더 표시 텍스트는 GXP 모드에서 설정합니다.
최대 28자까지 입력 가능하며, 화면 표시를 위해 14자씩 2줄로 자동 분할됩니다.
최대 글자수: 28자 (영문/숫자 기준)
표시 형식: 14자 × 2행
설정 방법
1내부 서비스 모드 → S-번호로 리마인더 주기(일) 설정
2GXP 모드 → 리마인더 메시지 텍스트 입력 (최대 28자)
3STANDBY 모드 진입 시 설정된 날짜 도달 여부 자동 확인
타임 채널Time Channels · 2.6.3
3개 채널로 열 소독 자동 실행, RUN 자동 시작/정지 예약
3채널 프로그래밍 자동 열 소독 303 OVERDUE HEAT
타임 채널 기능
타임 채널은 3개의 프로그래밍 가능한 시간 기반 채널을 제공합니다. 각 채널에 다음 동작 중 하나를 할당할 수 있습니다:
A자동 열 소독 시작 — 예약된 시각에 자동으로 열 소독 개시
B자동 RUN 시작 — 예약된 시각에 RUN 모드 자동 시작
C자동 RUN 정지 — 예약된 시각에 RUN 모드 자동 종료
표시등 상태
타임 채널이 활성화되어 있을 때 관련 표시등이 느리게 깜빡임(slow flash)으로 현재 타이머 대기 중임을 나타냅니다.

느린 깜빡임은 타임 채널이 활성 상태이며 예약된 시각을 기다리고 있음을 의미합니다.

303 OVERDUE HEAT 알람
설정된 열 소독 주기가 지났음에도 열 소독이 실행되지 않은 경우 303 OVERDUE HEAT 알람이 발생합니다.

303 OVERDUE HEAT 알람은 열 소독 미완료 상태를 나타냅니다. 즉시 열 소독을 실시하고 원인을 확인하세요.

설정 방법
1GXP 모드 또는 내부 서비스 모드 → 타임 채널 메뉴 진입
2채널 1~3 중 원하는 채널 선택
3채널별 동작(열 소독/RUN 시작/RUN 정지), 요일, 시각 설정
4설정 저장 — 이후 자동으로 예약된 동작 실행
