01 · Overview

이 도구로 할 수 있는 일

HTML 파일 하나를 브라우저로 열면 바로 쓸 수 있습니다. 파일은 외부 서버로 전송되지 않고 내 PC의 브라우저 안에서만 처리됩니다.

LOAD
드래그 & 드롭 분석
.dat 파일을 화면에 끌어다 놓으면 버전을 자동으로 감지해 바로 분석합니다. 여러 파일을 한 번에 넣을 수 있습니다.
ALARM LOG
전체 레코드 조회
발생 시각·타입·코드·설명을 표로 보고, 키워드·파일·타입으로 걸러내고, 컬럼 클릭으로 정렬합니다.
MACRO
파일별 고유 알람 요약
Excel 매크로의 "알람 확인 + CSV 변환"을 재현합니다. 파일마다 중복을 뺀 알람 목록을 날짜순으로 보여줍니다.
TRIAGE
카테고리별 우선 정렬
혈액회로·압력·전도도 등 11개 카테고리 중 하나를 고르면 해당 알람이 번호와 함께 맨 위로 올라옵니다.
EXPORT
CSV 내보내기
파일 단위 또는 전체를 CSV로 저장해 Excel Analysis Helper(Macro)에서 센서 값까지 이어서 분석할 수 있습니다.
OFFLINE
설치·인터넷 불필요
한 번 열린 뒤에는 인터넷 연결 없이도 동작합니다. 데이터는 브라우저 메모리에만 머뭅니다.

작업 흐름 한눈에

STEP 1
.dat 복사
장비에서 USB로 블랙박스 파일을 PC로 옮깁니다.
→
STEP 2
드롭
도구 화면의 점선 영역에 파일을 놓습니다.
→
STEP 3
탭에서 분석
Macro로 훑고 Triage로 좁히고 Alarm Log로 확인합니다.
→
STEP 4
CSV 저장
필요한 파일을 CSV로 받아 보고서나 추가 분석에 씁니다.
자세한 분석은 Excel Analysis Helper(Macro)로이 웹 도구는 알람 이력 확인·카테고리 분류·CSV 변환 등 현장에서의 빠른 1차 점검용입니다. 센서 값 추이 분석처럼 자세한 분석이 필요하면 Excel Analysis Helper(Macro)(.xlsm)를 사용하세요. 웹에서 내보낸 CSV(_1.csv)를 그대로 이어서 분석할 수 있습니다.
지원 브라우저Chrome, Edge, Safari, Firefox 최신 버전에서 동작합니다. Internet Explorer는 지원하지 않습니다.

A드롭존파일을 끌어다 놓거나, 영역을 클릭해 파일 선택 창을 엽니다. 선택 창에서는 Ctrl(⌘)+클릭으로 여러 파일을 고를 수 있습니다.
B진행 표시줄여러 파일을 넣으면 어떤 파일을 몇 번째로 처리 중인지 보여줍니다. 끝나면 결과 화면으로 바뀝니다.

단계별 순서

01
장비에서 .dat 파일 복사
Artis 투석기에서 USB 등으로 블랙박스 파일을 PC에 옮깁니다. 파일명은 BB12_YYMMDD_HHMM_…dat 또는 TalkFile_BB11_…dat 형태입니다.
02
드롭존에 파일 놓기
파일을 점선 영역 위로 끌고 오면 테두리 색이 바뀌고, 놓는 순간 분석이 시작됩니다.
03
버전 자동 감지 후 결과 표시
파일 크기로 8.09 / 8.33 / 8.60 / 9.05 중 하나를 판별해 모든 레코드를 읽습니다. 별도 설정은 필요 없습니다.
파일 추가는 초기화 후분석이 끝나면 드롭존이 사라집니다. 파일을 더 넣으려면 Reset(또는 Files 탭의 Clear All)을 누른 뒤, 분석할 파일을 모두 한 번에 다시 넣으세요.
Unsupported format / file size파일 크기가 지원 포맷 계산식과 맞지 않으면 이 오류가 표시됩니다. 복사 중 파일이 잘렸는지 확인하고, 다시 받은 뒤에도 같다면 기술지원 담당자에게 문의하세요.

휴대폰에서 USB로 바로 열기 (iPhone · iPad)

USB-C 단자가 있는 iPhone·iPad에는 장비의 USB 메모리를 PC 없이 바로 연결해 .dat 파일을 열 수 있습니다. 현장에서 파일을 옮기는 단계 없이 곧바로 분석할 수 있습니다. (아래 화면은 iPhone 기준입니다.)

여러 파일은 한 번에PC와 마찬가지로 분석이 끝나면 드롭존이 사라집니다. 파일을 더 넣으려면 Reset을 누르고, 분석할 파일을 모두 한 번에 다시 선택하세요.
표는 옆으로 밀어서 보기휴대폰 화면에서는 표가 화면보다 넓어 일부가 가려집니다. 표 위를 좌우로 밀면 나머지 열(Type · Code · Description · CSV)이 보입니다. 상단 탭(Alarm Log · Files · Macro · Triage)도 좌우로 밀 수 있습니다.
USB가 보이지 않을 때파일 앱의 둘러보기 → 위치에 USB 이름이 나타나야 합니다. 나타나지 않으면 케이블·USB 메모리를 다시 연결하고, 그래도 안 되면 PC로 파일을 옮긴 뒤 위 방법으로 불러오세요.

Macro — 파일별 고유 알람 요약

A정렬 버튼파일 시작 시각 기준으로 최신순(기본) 또는 오래된 순으로 바꿉니다. 선택된 버튼은 보라색으로 채워집니다.

08 · CSV Export

CSV 내보내기

CSV에는 화면 표에 없는 센서·상태 컬럼까지 전부 들어갑니다. 알람 전후의 압력·온도·전도도 값을 보려면 CSV를 받으세요.

위치버튼받는 범위
Alarm Log 상단↓ Export All CSV불러온 모든 파일 — 파일마다 CSV 1개씩
Alarm Log · Triage 각 행↓ CSV그 행이 속한 파일 전체 (행 하나만이 아님)
Macro 각 행↓ CSV그 파일 전체
Files 카드↓ CSV그 파일 전체

파일명 규칙

원본 파일명에서 .dat를 떼고 _1.csv를 붙입니다. Excel 매크로 결과물과 같은 이름이라 기존 분석 파일과 바로 비교할 수 있습니다.

IN
BB12_200326_0703_C400AD3B7AF2_33434.dat
OUT
BB12_200326_0703_C400AD3B7AF2_33434_1.csv

파일 크기가 아래 계산식 중 하나와 정확히 맞으면 그 버전으로 판별합니다. N은 레코드 수입니다.

버전헤더레코드 1개파일 크기 계산식
8.09255 B492 B255 + N × 492
8.33259 B520 B259 + N × 520
8.60262 B540 B262 + N × 540
9.05263 B540 B263 + N × 540

레코드 안에서 읽는 값

바이트 위치형식내용
0 – 3uint32 LEUnix 타임스탬프 → Date / Time
6 – 7uint16 LE타입 코드 (0 = ALARM, 1 = OPERATOR_ACT, 2 = SET_CNF_VALUE, 4 = AUTOMATIC …)
8 – 11uint32 LE레코드 번호 (CSV의 Rec. N.)
16 – 19uint32 LE알람 기술 코드 → 내장 목록에서 설명 조회 (ALARM 행)
알람 설명 범위코드 #1 – #678 가운데 356개의 설명이 내장되어 있습니다. 목록에 없는 코드는 Unknown Error로 표시되므로, 코드 번호로 서비스 매뉴얼을 찾아보세요.
10 · Troubleshooting

자주 묻는 질문

현장에서 자주 받는 질문을 모았습니다.

Q센서 값까지 자세히 분석하려면 어떻게 하나요?
웹 도구는 알람 중심의 1차 점검용입니다. 자세한 분석은 Excel Analysis Helper(Macro)(.xlsm)를 사용하세요. 웹에서 내보낸 CSV를 이어서 분석하거나, 원본 .dat 파일을 Excel 매크로로 처리할 수 있습니다.
Q휴대폰에서 파일을 어떻게 넣나요?
점선 드롭존을 탭하고 파일 선택을 고른 뒤, 파일 앱에서 .dat 파일(USB 메모리 포함)을 체크하고 열기를 누르세요. 자세한 화면은 02 파일 불러오기의 '휴대폰에서 USB로 바로 열기'를 참고하세요.
Q"Unsupported format / file size"가 나옵니다.
파일 크기가 4가지 포맷 계산식과 맞지 않는 경우입니다. USB 복사 중 잘렸거나 다른 종류의 파일일 수 있습니다. 장비에서 다시 받아 보고, 그래도 같으면 파일을 기술지원 담당자에게 전달하세요.
Q파일을 더 추가하고 싶은데 드롭존이 없어요.
분석 후에는 드롭존이 숨겨집니다. Reset(또는 Clear All)을 누르면 다시 나타납니다. 함께 볼 파일은 처음부터 한 번에 모두 넣는 것이 좋습니다.
Q알람 설명이 "Unknown Error"로 나옵니다.
내장 목록(356개)에 없는 코드입니다. Code 컬럼의 번호로 서비스 매뉴얼의 알람 표를 확인하세요.
QExport All CSV를 눌렀는데 파일이 하나만 받아졌어요.
브라우저가 여러 파일 동시 다운로드를 막은 경우입니다. 주소창 오른쪽의 다운로드 차단 아이콘에서 이 페이지를 허용한 뒤 다시 누르세요. 또는 Macro 탭에서 파일별 CSV 버튼을 하나씩 눌러도 됩니다.
QTriage 카테고리 버튼에 숫자가 없어요.
불러온 파일에 그 계통 알람이 없다는 뜻입니다. 눌러도 "해당 알람 없음"으로 표시되고 나머지 알람만 아래에 나옵니다.
Q환자 데이터가 외부로 나가지 않나요?
파일은 브라우저 메모리에서만 처리되며 어떤 서버로도 전송되지 않습니다. 탭을 닫거나 새로고침하면 모두 사라집니다. 받은 CSV 파일은 사내 보안 규정에 따라 보관하세요.
QAlarm Log에 5,000건까지만 보여요.
화면 속도를 위해 5,000행까지만 그립니다. 파일·타입 필터나 검색으로 좁히면 나머지도 볼 수 있고, CSV에는 항상 전체가 들어갑니다.
